Qwen (Alibaba)

Quick Setup

1. Login to chat.qwen.ai
2. Open DevTools (F12) → Console → type localStorage.getItem('token')
3. Copy the JWT token (starts with eyJ...)
4. Paste it above and click Save

Use guest as token for guest mode (no login required, limited functionality). Supports multiple tokens separated by commas for load balancing.
